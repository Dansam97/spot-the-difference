**Twin Vistas** — an original spot-the-difference game that plays offline in a desktop browser from its own static files. Three hand-drawn canvas scenes (Lantern Bay at dusk, Fernwood Hollow in the afternoon, the Clockwork Market fair) each hide a set of quiet changes between two near-identical pictures: 5, then 7, then 9 differences. Click a difference in either picture to ring it on both; a wrong click costs 5 seconds, hints are limited and shimmer around a hiding difference, and the clock is always running. Every scene is drawn procedurally by the game's own code — no image files, no network, synthesized sounds only.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or open game/index.html from any static server
```
